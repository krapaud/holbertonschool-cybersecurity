# 3x06 Capstone : The Defensive Architect

## Statut

Projet en cours. Ce document deviendra le master architecture document.

## Mission

Analyser la situation de Nexus Financial et proposer un programme de sécurité cohérent couvrant la gouvernance, la prévention, la détection et la réponse.

## Organisation du projet

```text
3x06_defensive_architect/
├── policy/
├── technical/
└── audit/
```

## Méthode de travail

1. Identifier les risques à partir des notes du brief.
2. Relier chaque risque à un contrôle précis.
3. Documenter les décisions avant d'écrire les scripts.
4. Rendre les scripts reproductibles et idempotents.
5. Garder les preuves et les résultats de validation dans `audit/`.

## Livrables

Les détails et les réponses seront complétés progressivement pendant le projet.
